# Router confidence: route only when confident

Generated by `scripts/router_confidence.py`; regenerated byte-identical on every run (do not edit by hand).

Model: **V-token (C=8)**, the variant selected on the 2023 validation slice by `scripts/router_text_baseline.py`. Same cut: C chosen on a slice of train (fit on created_at < 2023-01-01, top-1 on the 2023 slice), final model retrained on the whole train (< 2024-01-01). The 2023 validation slice is scored by the model trained on created_at < 2023-01-01 only (so it has never seen the validation slice), and the test slice (>= 2024-01-01) is scored by the final model — reference only, and never used for selection.

Two confidence signals per issue, from the V-token `predict_proba`:

- **top1** — probability of the first (top) component.
- **margin** — top1 minus the second-highest probability.

An issue is *auto-routed* when its signal is >= threshold t; its auto-routed prediction is the top-1 component. Precision is the top-1 hit rate among the auto-routed issues.
